# Vehicle Rental System

A simple Vehicle Rental System website developed as a college project.

## Features

- View available vehicles
- Search vehicles by type
- Search vehicles by brand
- Book a vehicle
- Calculate rental cost
- Security deposit
- Return vehicles
- Late-return penalty
- Deposit refund
- Real-time availability status

## Technologies Used

- HTML
- CSS
- JavaScript
- Java (console-based OOP project)

## Vehicle Details

The system demonstrates rental management for:

- Cars
- Bikes
- Vans

## Project Purpose

This project demonstrates Object-Oriented Programming concepts such as classes, objects, encapsulation, interfaces, and polymorphism.
